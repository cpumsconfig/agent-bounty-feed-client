Four layers, not one list

1 · What is out there

earn-now, feed, mcp — the same board over three transports, with --json for machines.

2 · Is it worth doing

check counts the PRs already open on a bounty and whether the repo still merges anything.

3 · Which one, out of all of them

check --all triages the whole board and puts the unclaimed work at the top.

4 · When something new appears

watch polls on an interval, dedupes against a state file, and reports only what is new.

Also

get and new for the other two MCP tools, --closes-within for deadlines, and mcp-config to paste into your host.

Layer 2 is the one that matters

Listing bounties is the easy half. The hard half is that most of them already have ninety pull requests open on them. check answers that in one command:

$ python3 abf.py check algora:onyx-dot-app/onyx#2281

onyx-dot-app/onyx#2281  Jira Service Management Connector
----------------------------------------------------------------------------
state      open, opened 2024-08-30 (791 days ago), 176 comments
competing  98 PR(s) mention this issue
repo       90 of the last 100 closed PRs merged (90 per 100)

verdict    CROWDED — 98 PRs already compete
           you would be entry 99; skip it

Three numbers decide it: PRs already open, merges out of the last hundred closed PRs, and how old the issue is. More than ten PRs is crowded. Fewer than five merges means the repo has stalled and the reward may never move. Older than a week means the field is already in.

The number that actually matters

A board total is not the set of tasks a caller can start. reachable subtracts a friction requirement and a crowded contest, and shows what each subtraction cost. A So far N paid / M rejected. sentence stays on that task. It is not a source lifetime:

listed     24 items  $50,716.1
reachable  14 items  $263.1      -10  kyc 9, purchase 1
winnable   11 items  $161.1      -3  crowded (50+ submissions)

Friction comes from requires. The contest cut uses the feed's own N submissions figure, and a task that does not report one stays in. Paid/rejected prose is listed per task. A missing sentence stays unknown. Sample tiers are from feed generated_at 2026-11-01T01:45:14Z.

Filter out work you cannot start

Half of any board needs KYC, a stake, a bond, a purchase, or a human. One flag removes all of it — on the current board, 25 listings become 15:

$ python3 abf.py earn-now --no-friction
$ python3 abf.py earn-now --exclude-requires kyc,stake

What the MCP transport actually does

Four JSON-RPC requests over Streamable HTTP. The client handles both response framings and the session rule that breaks naive implementations:

StepWhat comes back
initialize200, plus Mcp-Session-Id if the server is stateful
notifications/initialized202, empty body
tools/list200, application/json or text/event-stream
tools/call200, the payload sits in result.content[].text

This particular server is stateless and issues no session id — so the client only sends the header when the server gave it one. Hard-coding it either way breaks half the servers you will meet.
